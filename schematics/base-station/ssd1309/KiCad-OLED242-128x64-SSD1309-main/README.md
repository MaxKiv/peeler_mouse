# Footprint and symbol for OLED display 2.42"
KiCad footprint and symbol for OLED display 2.42" SPI/I2C SSD1309 128x64 (7 pins on top)

<br>

The footprint fits well with this 3D model from GrabCAD: https://grabcad.com/library/oled-2-42-v-4-1-1

<br>

This display is commonly available on AliExpress and through various sellers on Amazon. The exact model used to create this footprint is available on AliExpress: https://es.aliexpress.com/item/1005002766729064.html
